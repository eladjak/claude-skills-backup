# Web Design Stack

## Workflow: Design → Assets → Build → Verify
1. **Stitch MCP** → Design screens (`build_site`, `get_screen_code`)
2. **Gemini** → Generate ALL visual assets (nano-banana-poster)
3. **ReactBits** (reactbits.dev) + **shadcn/ui** → Components
4. **Claude Code** → Logic, state, backend
5. **React Doctor** → `npx -y react-doctor@latest .`
6. **Accessibility** → `/rams` command

## Animation: Only transform/opacity. Max 200ms for feedback.
