# Web Paradigm: Interaction > Information

Every web page should ask: "What can the visitor DO here?" — not just read.

## Two rules for every web project:

1. **Agent-First**: Expose an API (REST/MCP). Agents don't browse — they query.
2. **Human-Experience**: Replace static content with interactive elements.

| Static (Dead) | Interactive (Alive) |
|---|---|
| FAQ accordion | Chat interface with typing animation |
| Portfolio gallery | Project explorer with filters + live demos |
| Contact form | Conversational step-by-step form |
| Services list | Service configurator / quote builder |
| Pricing table | ROI calculator |

## API Checklist
